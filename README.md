# 学习中枢 · StudyHub

一个**单文件、零依赖**的本地学习管理工具：把课程视频、知识点笔记、划词高亮、手写演算和思维导图放进同一个页面，学习记录保存在本机，不需要注册和联网。

## 1. 项目解决什么问题

看网课时的痛点通常是这样的：

- 视频在 B 站、笔记在记事本、演算在草稿纸，**知识分散在三四个地方**；
- 想回看"极限保号性"是哪一讲讲的，只能凭记忆翻目录；
- 在网上做笔记要注册账号，数据存在别人服务器上不放心。

StudyHub 把这些收进一个 HTML 文件：**课程按"章 → 节"组织，学到哪打卡到哪，任何名词随手高亮、随手批注，还有一块手写画板随时演算**。所有数据只存在你自己的电脑上（浏览器 localStorage），关掉网页下次打开还在。

## 2. 主要功能

| 功能 | 说明 |
|---|---|
| 课程卡片首页 | 内置两门课：高等数学·武忠祥 0 基础课（12 章 46 讲）、C 语言入门示例课程（2 章 4 讲） |
| 章节学习视图 | 每讲一个独立页面，显示本章在本讲的知识点，可标记"已学"打卡 |
| 进度统计 | 首页和章节页实时显示"已学 x / y 讲（百分比）" |
| 全局搜索 | 顶部搜索框跨课程检索知识点、概念、习题关键词，点击结果直接跳到对应讲次 |
| 划词高亮 | 选中正文任意文字即可高亮标记，重开页面不丢失 |
| 批注与自定义补充 | 对高亮处写批注，也可以往任何一讲添加自定义补充卡片 |
| 手写画板 | 每讲配备手写层：画笔颜色/粗细可调、橡皮擦、撤销、一键清空，适合演算和画图 |
| 思维导图 | 以思维导图形式展示课程章节结构，可一键展开全部 |
| 批注导出 | 一键把全部高亮和批注导出为 JSON 文件保存到本地 |
| 桌面版 | 用 Neutralino 打包成 Windows exe（约 2.4MB，WebView2 渲染），双击即用，无需浏览器 |

## 3. 安装方法

**方式一：网页版（最简单）**

1. 下载本仓库的 `index.html`；
2. 双击用任意现代浏览器（Edge / Chrome）打开即可，无需安装任何东西。

**方式二：Windows 桌面版**

1. 下载 `StudyHub-win_x64.exe` 和 `resources.neu`（两个文件必须放在**同一个文件夹**）；
2. 双击 `StudyHub-win_x64.exe` 运行；
3. 要求 Windows 10/11（系统自带 WebView2 运行时，无需额外安装）。

## 4. 使用方法

1. **进课程**：首页点击课程卡片（如"高等数学·武忠祥 0 基础课"）进入章节列表；
2. **学一讲**：点击章节条目进入学习视图，看完视频/内容后点"已学"打卡；
3. **划重点**：在学习视图中用鼠标选中一段文字 → 点击高亮，文字立即标记；
4. **写批注**：高亮后可附加批注文字；也可以点"添加补充"往本讲塞自己的卡片；
5. **手写演算**：点画板按钮唤出手写层，选颜色和笔宽直接写画，写错用橡皮或撤销，整页不要了点清空；
6. **找东西**：顶部搜索框输入关键词（如"中值定理"），回车后在结果里点任意一条直达对应讲；
7. **看结构**：进入"思维导图"视图总览整门课的章节树；
8. **备份数据**：点右上角"导出我的批注"，得到 JSON 文件妥善保存。

## 5. 输入输出示例

**例 1：全局搜索**

- 输入：在搜索框输入 `极限`
- 输出：命中"第 1 章 函数与极限"下多个讲次的列表，例如：

```
高等数学·武忠祥 0基础课 › 第1章 › 第3讲：无穷小与无穷大
高等数学·武忠祥 0基础课 › 第1章 › 第5讲：极限的运算法则
```

点击任意一条 → 直接打开那一讲的学习视图。

**例 2：学习打卡**

- 输入：在第 2 讲页面点击"标记为已学"
- 输出：进度条从 `已学 0/46 讲（0%）` 变为 `已学 1/46 讲（2%）`，首页同步更新

**例 3：划词高亮 + 批注**

- 输入：选中正文中的"两个重要极限"四字 → 点高亮 → 输入批注"必考，证明要会默"
- 输出：该词以高亮底色显示，鼠标悬停/点击可见批注内容；刷新或重开页面后依然存在

**例 4：导出批注**

- 输入：点击"导出我的批注"
- 输出：浏览器下载 `studyhub-notes.json`，内容结构大致为：

```json
{
  "course:gaoshu:ch1:l3": {
    "highlights": [
      { "text": "两个重要极限", "note": "必考，证明要会默", "time": "2026-10-27 16:40" }
    ],
    "extras": [],
    "done": false
  }
}
```

---

**技术构成**：单文件 HTML + 原生 JavaScript + CSS（无框架、无构建、无网络请求）；桌面版使用 Neutralino.js（WebView2 内核）打包。数据 100% 存储在本机浏览器 localStorage 中，导出功能用于手动备份。
