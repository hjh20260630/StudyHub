使用说明

🧭 三层结构

首页是课程卡片 → 点进课程是思维导图（章节分叉出每一课）→ 点某一课进入内容页，包含知识点、概念、代码和习题。

🔍 搜索

顶栏搜索框全局搜索，输入关键词后点结果，会直接打开对应课程并定位到那条知识点（黄色闪烁提示）。快捷键：/ 聚焦搜索框。

🖍 高亮与画笔

  • 鼠标选中一段文字 → 点浮出的「🖍 高亮」按钮，即可标黄；点已高亮的文字可取消。
  • ✏️ 画笔批注：内容页点「画笔」开启后，可像拿笔一样在页面上任意涂画（5 种颜色、粗细可调），支持擦除、撤销、清空，自动保存。笔迹按页独立：每一页的画笔只留在那一页。
  • 每课底部有「我的补充」，可以自己往里面加内容（笔记、心得、易错点），支持 Ctrl+V 粘贴视频截图；补充内容也是按页独立的。

⚠️ 数据保存在哪：桌面版（exe）自动写入本机 %LOCALAPPDATA%\StudyHub\data.json，重启/重装应用都不会丢；浏览器版保存在浏览器 localStorage 中（换浏览器或清缓存会丢失）。重要内容请定期点顶栏「导出我的批注」备份成 JSON 文件。

📖 课程内容怎么加？

所有课程内容以 JSON 形式写在源文件顶部 COURSE_DATA 里，格式如下（把书和课程发给小智，会自动帮你填进去）：

{
  id: "c1", title: "课程名", desc: "一句话简介", color: "#4f6ef7",
  chapters: [           // 章节（导图的第一层分叉）
    { id: "ch1", title: "第一章",
      lessons: [        // 每一课（导图的第二层分叉）
        { id: "l1", title: "课名", blocks: [
          { t:"p",       x:"普通段落" },
          { t:"h",       x:"小标题" },
          { t:"concept", title:"概念名", x:"概念解释" },
          { t:"code",    lang:"c", x:"代码…" },
          { t:"list",    items:["要点1","要点2"] },
          { t:"quiz",    q:"习题", a:"答案" }
        ]}
      ]}
  ]
}

支持的知识块类型：p 段落 / h 小标题 / concept 概念框 / code 代码 / list 要点列表 / quiz 习题（点按钮看答案）。
